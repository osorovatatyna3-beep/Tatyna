# Варианты рекламных текстов: Uniqom.ned

## Вариант 4 — через доверие

### Исходный (от Татыны, 2026-09-23)
```
Ваш новый дом — без ожидания годами
✓ Сдаём объекты в срок
✓ Сразу подключаем коммуникации
✓ Продуманные квартиры и таунхаусы
📍 Бишкек
👇 Актуальные предложения
```

### Проблема
"Сдаём объекты в срок" — непроверяемое обещание. По brief.md это первый видимый проект, аккаунт новый, оба объекта ещё в стройке (3 и 2 этаж соответственно), завершённых сдач ещё не было. Скептик, которого этот вариант должен убедить, скорее всего не найдёт подтверждения — и главное возражение проекта ("нас плохо знают") не снимается, а усиливается.

**Открытый вопрос:** если у собственника ЕСТЬ прошлые сданные объекты (не Дагестанская 5 / Кок-Жар) — использовать с конкретикой (какой объект, когда сдали). Если нет — не давать это обещание вообще.

### Улучшенная версия (2026-09-23) — доверие через прозрачность, не через непроверяемое обещание
```
Новый дом в Бишкеке — стройка у вас на глазах

✓ Показываем стройку в реальном времени, а не только рендеры
✓ Полный набор коммуникаций входит в цену: свет, вода, канализация, газ
✓ Рассрочка до 18 месяцев — без банка и переплат
✓ Возможен бартер: авто, вторичное жильё, участок

📍 Бишкек, Дагестанская 5 / Кок-Жар
👇 Запишитесь на просмотр объекта — в WhatsApp
```

Что изменено:
- Убрано недоказуемое "сдаём в срок" → заменено на то, что реально можно показать (стройка на камеру с датой — уже в content-plan-template.md, идея "Стройка на сегодня")
- "Сразу подключаем коммуникации" → расписано конкретно по составу ПСО (brief.md)
- Добавлены рассрочка и бартер — реальные УТП компании из brief.md, которых не было в исходнике
- CTA заменён на конкретное целевое действие (запись на просмотр в WhatsApp) вместо расплывчатого "актуальные предложения" — совпадает с воронкой заявок (brief.md)
