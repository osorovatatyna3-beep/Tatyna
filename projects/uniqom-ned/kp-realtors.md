# Коммерческое предложение для риелторов и агентств недвижимости

## Статус
- Дата: 2026-10-02
- Цель: партнёрство с риелторами/агентствами Бишкека — комиссия за закрытую сделку
- Связано с: `media-plan.md` → «Дополнительные каналы продвижения» (пункт 1 — самый быстрый канал из предложенных)

## Что нужно уточнить перед финальной версией
- [ ] Точный % комиссии (ориентир 2-3%, подтвердить у собственника)
- [ ] Момент выплаты (после договора / первого взноса / полной оплаты)
- [ ] Механика фиксации клиента агентства (кто первый, как избежать споров)
- [ ] Эксклюзивность (да/нет)
- [ ] Материалы, которые передаём агентствам (прайс, планировки, фото/видео, доступ на показ)
- [ ] Контактное лицо/номер для агентств
- [ ] Приоритетный объект для продвижения через риелторов
- [ ] Срок действия предложения (из-за удорожания +$100/м² на Дагестанской при 6 этаже)
- [ ] Формат — договор или работа по КП+переписке на старте
