# Скрипты продаж: Direct / WhatsApp / Комментарии

## Статус
- Дата: 2026-10-03
- Для кого: 2 менеджера по продажам, обрабатывающих входящие вручную (см. brief.md → «Отдел продаж»)
- Цель — везде одна: довести клиента до записи на просмотр (целевое действие из «Воронки заявок» в brief.md)

## Общие принципы
- Все три канала (Direct, комментарии, WhatsApp) — точки входа в одну воронку: планировки → расчёт стоимости/рассрочки → запись на просмотр
- В комментариях — никогда не называть цену/условия публично, уводить в личные сообщения
- Если клиент пришёл по рекомендации жильца — спросить код/номер квартиры рекомендателя для реферальной программы (см. `referral-program-flyer.md`) и занести в таблицу учёта (`media-plan.md`)
- Скорость ответа критична — при 2 менеджерах вручную задержка = потерянный лид

## Первый ответ — что отправлять сразу, как только написали (2026-10-07)
Универсальный шаблон, работает и в WhatsApp, и в Direct — это то самое первое сообщение, от которого зависит, продолжит ли человек разговор. По образцу хорошего примера от kutstroy (их консультант Айлин): представиться по имени, поблагодарить за обращение, сразу 1-2 квалифицирующих вопроса — не вываливать сразу весь прайс.

```
Здравствуйте! 😊 Меня зовут [имя], я менеджер по продажам
компании Uniqom.ned (Юником Строй).

Спасибо, что написали нам!

Подскажите, пожалуйста:
— Вас интересует квартира (Дагестанская 5) или таунхаус
  (Кок-Жар)?
— Какая площадь или бюджет вам ближе?

Как только уточним — пришлю актуальные планировки, цены
и условия рассрочки 🏠
```

После этого ответа клиент переходит в воронку ниже (этапы «Планировки» → «Расчёт» → «Запись на просмотр»).

## Скрипт для Direct (Instagram)
Обычно пишут после Reels/сторис с вопросом о цене/подробностях.

```
Здравствуйте! 😊 Меня зовут [имя], отдел продаж Uniqom.ned.
Спасибо за интерес к нашему объекту!

Подскажите, пожалуйста:
— Вам интересна квартира (Дагестанская 5) или таунхаус (Кок-Жар)?
— Примерно на какой бюджет ориентируетесь?

Так я сразу подберу подходящий вариант и пришлю актуальные
планировки, цены и условия рассрочки.

Удобнее продолжить в WhatsApp — там отвечаю быстрее и сразу
отправлю все материалы. Напишите свой номер, либо вот наш:
+996 (0709) 007-171 🙂
```

Если сразу спрашивают цену:
```
Цена зависит от площади и объекта — от $40 800 за квартиру
34 м² до $132 000 за таунхаус 110 м². Есть рассрочка (от 50%
первый взнос) и возможность бартера (авто/жильё/участок).
Пришлю точный расчёт под ваш бюджет в WhatsApp — напишите,
пожалуйста, номер 🙂
```

## Скрипт для WhatsApp (основная воронка)

**1. Приветствие + квалификация:**
```
Здравствуйте, [имя]! Меня зовут [менеджер], Uniqom.ned 🏗
Подскажите:
— Квартира или таунхаус интересует?
— Какая площадь примерно нужна?
— Рассматриваете рассрочку или полную оплату?
```

**2. Этап «Планировки»:**
```
Отправляю планировки и фото наших объектов:
📍 Дагестанская, 5 — квартиры 34–74 м², $1200/м²
📍 Кок-Жар — таунхаусы 110 м², $1200/м²

Что-то приглянулось? Посчитаю точную стоимость и варианты
рассрочки под вас.
```

**3. Этап «Расчёт»:**
```
Квартира [34/54/74] м² — [сумма] $.
Варианты оплаты:
— Рассрочка: 50% первый взнос, остаток на 18 мес
— Полная оплата: скидка -$50/м²
— Бартер: авто, вторичное жильё, участок (оценка по факту)

Хотите подробный расчёт по месяцам? И когда вам удобно
подъехать посмотреть объект вживую?
```

**4. Этап «Запись на просмотр» (целевое действие):**
```
Отлично! Записываю вас на просмотр.
Удобнее [дата/время] или [дата/время]?
Адрес: [объект]. Скину геолокацию ближе ко времени 📍
```

**Если клиент пришёл по рекомендации жильца:**
```
Отлично, подскажите код/квартиру того, кто вас направил —
занесу в систему, это важно для бонуса вашему знакомому 🙂
```

## Скрипт для комментариев (публичные, под постом)
Правило: **никогда не называть цену и условия в открытом комментарии**. Задача комментария — увести в личку, затем в WhatsApp.

**Общий шаблон:**
```
Здравствуйте! Написали вам в Direct 📩
```
(и сразу написать в директ с квалифицирующим вопросом из скрипта Direct выше)

**Под частые вопросы:**

«Сколько стоит?»
```
Здравствуйте! Цена зависит от площади — пришлём точный расчёт
в директ 🙂
```

«Есть рассрочка?»
```
Да, есть! Напишем подробнее в личные сообщения 📩
```

«А фото/видео объекта есть?»
```
Конечно, скинем в Direct полную подборку 😊
```

## Обработка возражений (во всех каналах)

**«Не слышал о вашей компании»**
```
Понимаю! У нас уже есть сданные и заселённые дома — там живут
люди, газ/свет/вода подключены и работают. Можем показать
видео или даже организовать визит к текущим жильцам.
```

**«Рассрочка мне не по карману»**
```
Подскажите, какой первый взнос был бы комфортен? Подберём
вариант — например, квартиру меньшей площади с тем же
качеством, или обсудим бартер, если есть авто/жильё на обмен.
```

**«Дорого / торг»**
```
Цена фиксированная, но если оплатите полностью сразу — скидка
$50 за м². Также сейчас актуальная цена, при достройке
следующего этажа она вырастет на $100/м² — выгоднее решить
сейчас.
```
